# Hotel Reservation System

## About the Project
Hotel Reservation System is a simple console-based Java application that helps users manage hotel room bookings. Users can view room availability, book rooms, check booking details, and cancel reservations.

This project was developed to practice Java programming fundamentals.

## Features
- View all rooms and their availability status.
- Book an available room.
- Store customer names with room numbers.
- View booking details and total booked rooms.
- Cancel existing reservations.
- Display the total number of available rooms.
- Validate menu input and room numbers.
- Prevent booking with an empty customer name.
- Handle invalid non-numeric menu and room-number inputs.

## Technologies Used
- Java
- Scanner class
- Arrays
- Loops (`for`, `while`)
- Conditional statements (`if-else`)
- `switch-case`
- Input validation

## How to Run

**Step 1:** Make sure Java JDK is installed on your computer.

**Step 2:** Open a terminal in the project folder.

**Step 3:** Compile the Java file:

```bash
javac HotelReservationSystem.java
```

**Step 4:** Run the program:

```bash
java HotelReservationSystem
```
